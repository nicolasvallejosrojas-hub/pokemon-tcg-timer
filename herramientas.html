Con la beta cerrada, crear una cuenta pide un código; las cuentas que ya existen entran igual. Comparte el enlace: abre el registro con el código escrito. Un código de varios usos sirve para una tienda entera; al borrarlo deja de aceptar gente nueva, pero no borra las cuentas que ya lo usaron. Toda cuenta creada con un código gana la insignia Beta tester.
